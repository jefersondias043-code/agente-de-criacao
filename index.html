Dados e backup

Tudo é salvo apenas neste navegador. Exporte um backup para não perder seu trabalho — ou levá-lo para outro computador.

Uso do armazenamento —
—
Proteção das chaves de API —
Cifre suas chaves com uma senha (AES-GCM). Sem a senha, elas não ficam legíveis no navegador nem no backup. A senha não é salva — se esquecê-la, basta reconfigurar as chaves.
Reiniciar plataforma

Apaga todos os dados salvos neste navegador — históricos de todas as ferramentas, memórias, cartazes, projetos, configurações personalizadas e chaves de API — e restaura a plataforma ao estado inicial de uso. Esta ação não pode ser desfeita. Se quiser preservar algo, exporte um backup antes.
